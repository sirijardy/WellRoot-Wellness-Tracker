# 🌱 WellRoot – Daily Wellness Tracker

WellRoot is a simple and interactive wellness tracking web application designed to help users build healthy daily habits and maintain a balanced lifestyle.

## ✨ Features

- 💧 **Water Tracker** – Track daily water intake.
- 🍎 **Food Tracker** – Add, edit, and delete food entries while tracking calories and protein.
- 🏃 **Exercise Tracker** – Record workouts and monitor exercise minutes.
- 😴 **Sleep Tracker** – Track daily sleeping hours.
- 📅 **Daily Schedule** – Organize daily tasks and mark them as completed.
- 🌿 **Daily Habits** – Track healthy habits and view completion progress.
- 💬 **Motivational Quotes** – Get encouraging quotes and healthy living tips.
- 💾 **Local Storage** – Save daily tracking data in the browser.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Start tracking your daily wellness activities.

## 🎯 Project Goal

To encourage consistency in healthy living by making everyday wellness activities simple, organized, and enjoyable.
